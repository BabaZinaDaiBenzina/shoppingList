# PWA (Progressive Web App) - Офлайн версия

Приложение теперь поддерживает работу офлайн благодаря PWA функциональности.

## Что было настроено:

### 1. Service Worker
- **Файл**: `public/sw.js`
- **Стратегия кеширования**: NetworkFirst (сначала сеть, потом кеш)
- **Автообновление**: Service Worker автоматически обновляется

### 2. Манифест
- **Файл**: `app/manifest.ts`
- **Иконки**: 192x192 и 512x512 пикселей
- **Режим отображения**: Standalone (как нативное приложение)

### 3. Кеширование
- **Статические файлы**: JS, CSS, изображения
- **API запросы**: Кешируются автоматически
- **Лимит**: До 200 записей в кеше

## Как использовать:

### Установка на устройство:

#### Chrome (Android):
1. Откройте приложение в браузере
2. Нажмите на меню (⋮)
3. Выберите "Установить приложение" или "Добавить на главный экран"

#### Safari (iOS):
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (⎙)
3. Пролистайте вниз и нажмите "На экран Домой"

#### Chrome (Desktop):
1. Откройте приложение в браузере
2. В адресной строке нажмите на иконку установки (⊞)
3. Нажмите "Установить"

### Офлайн работа:
После первого посещения приложение кеширует все необходимые файлы. При отсутствии интернета:
- Приложение продолжит работать с кешированными данными
- При восстановлении соединения изменения синхронизируются

## Проверка PWA:

### Chrome DevTools:
1. Откройте DevTools (F12)
2. Перейдите в раздел "Application"
3. Проверьте разделы:
   - **Manifest**: Должен быть загружен
   - **Service Workers**: Должен быть активен
   - **Cache Storage**: Должен содержать кешированные файлы

### Lighthouse:
1. Откройте DevTools
2. Перейдите в раздел "Lighthouse"
3. Запустите аудит Progressive Web App
4. Оценка должна быть ≥ 90

## Сборка:

Для production сборки используется webpack (требуется для next-pwa):

```bash
npm run build
npm run start
```

В режиме разработки PWA отключено:

```bash
npm run dev
```

## Обновление:

Service Worker автоматически проверяет обновления при каждом визите. При обнаружении новой версии пользователю будет предложено обновить приложение.

## Troubleshooting:

### Service Worker не регистрируется:
1. Очистите кеш браузера
2. Удалите Service Worker в DevTools
3. Перезагрузите страницу

### Приложение не устанавливается:
1. Проверьте HTTPS (PWA работает только по HTTPS)
2. Проверьте манифест на ошибки
3. Убедитесь что все иконки доступны

### Офлайн режим не работает:
1. Проверьте что Service Worker активен в DevTools
2. Проверьте Cache Storage
3. Убедитесь что файлы закешированы

## Конфигурация:

Файл конфигурации: `next.config.ts`

Изменить настройки кеширования:
```typescript
runtimeCaching: [
  {
    urlPattern: /^https?.*/,
    handler: 'NetworkFirst', // или 'CacheFirst', 'StaleWhileRevalidate'
    options: {
      cacheName: 'offlineCache',
      expiration: {
        maxEntries: 200,
        maxAgeSeconds: 24 * 60 * 60 // 24 часа
      },
    },
  },
]
```
