# PWA Installation Guide

## Установка PWA на разные устройства

### iOS (iPhone/iPad)
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Прокрутите вниз и нажмите "На экран 'Домой' (Add to Home Screen)"
4. Нажмите "Добавить"

### Android (Chrome)
1. Откройте приложение в Chrome
2. Нажмите на меню (три точки) в правом верхнем углу
3. Выберите "Установить приложение" или "Добавить на главный экран"
4. Нажмите "Установить"

### Desktop (Chrome/Edge)
1. Откройте приложение в Chrome или Edge
2. В адресной строке справа нажмите на значок установки (⊕ или ⋮)
3. Нажмите "Установить"

## Возможности PWA

✅ **Работа офлайн** - Приложение работает без интернета
✅ **Автосинхронизация** - Данные синхронизируются при подключении
✅ **Push уведомления** - Возможность отправлять уведомления
✅ **Быстрый запуск** - Мгновенная загрузка
✅ **Аппаратное ускорение** - Использует возможности устройства
✅ **Шорткаты** - Быстрый доступ к функциям

## Manifest Features

### Shortcuts
- **Новый список** - Быстрое создание списка
- **Рецепты** - Доступ к книге рецептов

### Display Modes
- **Standalone** - Полноэкранный режим
- **Window Controls Overlay** - Современный режим с оверлеем

### Icons
- Маскируемые иконки для адаптации под разные устройства
- Поддержка всех размеров от 72x72 до 512x512

## Тестирование PWA

### Lighthouse
1. Откройте Chrome DevTools (F12)
2. Перейдите в раздел Lighthouse
3. Выберите "Progressive Web App"
4. Нажмите "Analyze page load"

### Проверка установки
- Проверьте, что Service Worker установлен (DevTools > Application > Service Workers)
- Проверьте Manifest (DevTools > Application > Manifest)
- Проверьте кэш (DevTools > Application > Cache Storage)
