# Тестирование PWA на мобильных устройствах

## 📱 Установка приложения

### iOS (iPhone/iPad)

1. **Откройте Safari** и перейдите на ваш сайт
2. **Нажмите "Поделиться"** (квадрат со стрелкой вверх, внизу экрана)
3. **Прокрутите вниз** и нажмите **"На экран «Домой»"**
4. **Нажмите "Добавить"** в правом верхнем углу
5. ✅ Иконка появится на главном экране

### Android (Chrome)

1. **Откройте Chrome** и перейдите на ваш сайт
2. **Нажмите меню (⋮)** в правом верхнем углу
3. **Нажмите "Установить приложение"** или "Добавить на главный экран"
4. **Нажмите "Установить"**
5. ✅ Иконка появится на главном экране

## ✅ Проверка офлайн режима

### Шаг 1: Первый запуск (онлайн)

1. **Откройте приложение** с главного экрана (НЕ через браузер!)
2. **Войдите в аккаунт**
3. **Откройте список покупок**
4. **Убедитесь, что данные загрузились**

**ВАЖНО**: При первом запуске приложение должно загрузить все данные в кэш!

### Шаг 2: Активация офлайн режима

1. **Включите авиарежим** или выключите интернет
2. **Откройте приложение** с главного экрана
3. ✅ Приложение должно загрузиться
4. ✅ Должны быть видны ранее загруженные списки

### Шаг 3: Проверка функциональности офлайн

В офлайн режиме должны работать:

- ✅ Просмотр списков
- ✅ Создание новых списков
- ✅ Добавление товаров
- ✅ Отметка товаров как купленные
- ✅ Удаление товаров
- ✅ Появляется индикатор "Офлайн режим"

### Шаг 4: Синхронизация

1. **Выключите авиарежим** / включите интернет
2. ✅ Должен появиться индикатор "Синхронизация..."
3. ✅ Все изменения отправятся на сервер
4. ✅ Индикатор исчезнет после синхронизации

## 🐛 Если не работает

### Проблема: Приложение не открывается офлайн

**Причины:**
1. Service Worker не установлен
2. Страница не кэширована при первом запуске
3. Проблемы с manifest

**Решение:**

1. **Удалите приложение** с главного экрана (удаление как обычного приложения)

2. **Очистите кэш Safari/Chrome:**
   - iOS: Настройки → Safari → Очистить историю и данные сайтов
   - Android: Chrome → Меню → История → Очистить историю

3. **Переустановите PWA:**
   - Откройте сайт в браузере
   - Дождитесь полной загрузки
   - Установите на главный экран заново

4. **Проверьте консоль:**
   - iOS: Настройки → Safari → Продвинутый → Web Inspector
   - Подключите iPhone к Mac
   - Safari → Разработка → [Ваш iPhone] → [Ваш сайт]

### Проблема: Service Worker не активен

**Проверка в консоли:**

```javascript
// На мобильном устройстве откройте консоль (через USB отладку)
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.getRegistrations().then(regs => {
    console.log('Registrations:', regs)
    console.log('Controller:', navigator.serviceWorker.controller)
  })
}
```

Должно показать:
- `Registrations: [ServiceWorkerRegistration]`
- `Controller: ServiceWorker`

Если `Controller: null` - SW не контролирует страницу!

**Решение:**
```javascript
// Принудительно активировать
navigator.serviceWorker.ready.then(reg => {
  reg.update()
})
```

### Проблема: Данные не синхронизируются

**Проверьте:**
1. Интернет включён?
2. Вы вошли в аккаунт?
3. Токен в localStorage валиден?

```javascript
// Проверить токен
console.log('Token:', localStorage.getItem('token'))

// Проверить очередь
await indexedDB.getQueue().then(q => console.log('Queue:', q))
```

## 📊 Отладка через USB

### iOS + Mac

1. **iPhone:** Настройки → Safari → Продвинутый → Web Inspector = ВКЛ
2. **Mac:** Safari → Разработка → [Ваш iPhone]
3. Выберите **ваш сайт** в списке
4. Откроется **Web Inspector** с консолью

### Android + Windows/Mac

1. **Телефон:** Настройки → О телефоне → Включите "Режим разработчика"
2. **Телефон:** Настройки → Для разработчиков → USB-отладка = ВКЛ
3. **Подключите к компьютеру через USB**
4. **Chrome:** chrome://inspect
5. Нажмите **Inspect** рядом с вашим сайтом

## ✅ Чек-лист для релиза

### Manifest
- [ ] `start_url: "/?standalone=true"`
- [ ] `scope: "/"`
- [ ] `display: "standalone"`
- [ ] Иконки 192x192 и 512x512 существуют
- [ ] `short_name` ≤ 12 символов

### Service Worker
- [ ] Регистрируется с `scope: "/"`
- [ ] Активен (`controller !== null`)
- [ ] Кэширует главную страницу
- [ ] Кэширует статические файлы

### Тестирование
- [ ] Устанавливается на iOS
- [ ] Устанавливается на Android
- [ ] Работает офлайн после первого запуска
- [ ] Синхронизация при восстановлении интернета
- [ ] Push-уведомления об обновлениях

## 🎯 Быстрая проверка на проде

### 1. PWA установлен?
Откройте приложение - должна быть строка состояния (без адресной строки браузера)

### 2. Service Worker активен?
В консоли: `navigator.serviceWorker.controller` не должен быть `null`

### 3. Кэш работает?
Включите авиарежим → обновите приложение → должно открыться

### 4. IndexedDB работает?
```javascript
await indexedDB.getAllShoppingLists().then(l => console.log('Lists:', l.length))
```

## 🔧 Исправление известных проблем

### Проблема: PWA не запоминается офлайн на iOS

**Решение:** Убедитесь что `start_url` в manifest начинается с `/`

### Проблема: Некорректный scale на мобильных

В `next.config.ts`:
```javascript
experimental: {
  optimizeCss: false
}
```

### Проблема: Не работает Touch ID / Face ID

Требуется HTTPS + валидный SSL сертификат
